How-to guides

A how-to is one task, with code the documentation build runs.

Building

  • Write a calculation: when no component in the library does what a part of the system does.

  • Wire a flow network: when components must sit on the edges of a loop and share its flows.

  • Choose a channel and its laws: when coolant flows past a heated wall.

  • Build a plate, an assembly or a rod: when the heat comes from a fuel plate, an assembly of plates or a rod.

  • Bind inputs and time schedules: when an input is a constant, a step or a table in time.

  • Add point kinetics, feedback and a trip: when the power follows reactivity and the rods drop on a trip.

  • Add decay heat: when the power after shutdown matters.

Solving

  • Get a steady solve to converge: when the steady solve fails or lands on the wrong flow direction.

  • Run a transient and set tolerances: when a transient starts from an operating point.

  • Trip, stop and restart: when a run stops at an event and continues after it.

  • Diagnose a failing solve: when a solve dies or its answer is wrong.

Reading

  • Read results: when a quantity is wanted out of a steady state or a transient.

  • Compute margins: when the question is how far the plate is from boiling.
